# Middleware POS System

Marketplace & Crowdfunding Platform for UMKM

## Description

A web-based application developed using Flask and SQLite that integrates marketplace and crowdfunding services.

## Features

- Multi-role Authentication
  - Admin
  - Investor
  - UMKM
  - Bank

- Marketplace Management
- Product Management
- Order Management
- Investment Management
- Funding Validation
- Dashboard Reporting

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
